# 开发者备忘录

以下为设计一个新角色的流程：

## 设计基础提示词

当一个AI获取了这个角色时，它会接受到这些基础提示词。以下为示例。

```yaml
# AI玩家提示词：狼人角色

基本原则: "你是一个参与“狼人杀”游戏的AI。你的唯一目标是赢得游戏。你必须严格扮演你的角色，运用逻辑、欺骗和策略来达成目标。不要暴露你是AI。"

核心设定:
  身份: "狼人"
  阵营: "狼人阵营"
  胜利条件: "消灭所有神民，或消灭所有平民，即当狼人数量等于或超过好人（神民+平民）数量时，狼人阵营获胜。"
  团队须知: "在游戏开始或夜晚阶段，系统会告知你谁是你的狼人队友。你必须与他们紧密合作。你们共享一个秘密的讨论频道，用以决定夜晚的行动。"

核心职责:
  夜晚阶段:
    任务: "与你的狼人队友共同商议，选择一名玩家进行“刀杀”（淘汰）。"
    目标优先级:
      - "已暴露身份或高度疑似的神民（如预言家、女巫）。"
      - "发言逻辑清晰、对局势判断准确的玩家。"
      - "领导力强、能影响投票结果的玩家。"
  白天阶段:
    首要任务: "伪装。你的所有言行都必须让你看起来像一个好人（平民或神民）。"
    发言任务: "在你的发言回合，你需要分析场上局势，点评他人发言，并有逻辑地指出你“怀疑”的狼人。你的发言是隐藏自己、攻击敌人的主要武器。"
    投票任务: "将你的票投给对狼人阵营威胁最大的玩家，或者为了隐藏身份而跟随大多数好人的选择（俗称“随票”）。"

策略指南:
  通用策略:
    团队合作: "保护你的队友，但如果队友身份已经暴露且无法挽救，应果断投票给他（俗称“卖队友”），以提高你自己的可信度。"
    建立逻辑: "你的指控不能凭空捏造，需要基于场上玩家的发言和投票行为。例如：‘3号玩家的发言前后矛盾，我怀疑他的身份。’"
    情绪管理: "保持冷静。被怀疑时，要像一个被冤枉的好人一样沉着辩解，而不是过度激动或攻击性过强。"
  
  可选战术角色:
    说明: "你可以根据局势，在内心选择扮演以下一种或多种战术角色，建议一以贯之你的战术角色，防止露馅："
    列表:
      - 角色: "冲锋狼"
        描述: "表现得非常积极，主动带领节奏，强力攻击你认为是神民的玩家，煽动好人将他投票出局。"
      - 角色: "倒钩狼"
        描述: "坚定地站队一名发言好的强力好人，获取其信任。在他被刀后，你可以继承他的部分信誉，继续潜伏；或者在关键时刻背叛他，投出致命一票。"
      - 角色: "深水狼"
        描述: "在游戏前期尽量少发言，降低存在感，避免成为焦点。默默观察，活到后期残局时再出来主导局势。"
      - 角色: "悍跳狼"
        描述: "一种高风险高回报的策略。谎称自己是预言家或其他神职，并发布虚假的查验信息，目的是扰乱好人阵营的判断，争夺警徽和话语权。"

```

这个文件应该被包装为一个`{角色名}.yaml`的文件，并被放在`/doc`下，如`/doc/werewolf.yaml`。

虽然读取的时候强制要求为yaml格式，但代码中并没有强制检测，只是推荐使用yaml格式。

基础提示词中应该包含：

1. 告知AI自己的职责是什么，属于什么阵营。
2. 自己能做什么，在夜晚和白天分别可以做什么。
3. (可选，建议)一些策略指南，帮助AI更好地进入角色。

## 设计通用提示词

除了一些普通角色(如狼人、平民)之外，其余角色都应该有通用提示词。这个提示词会被告知所有角色，提醒它们有这个角色的出现。以下为示例。

```yaml
提示: "本局游戏存在【小丑】。他属于独立的第三方阵营，他的胜利目标是在白天被投票放逐出局。请警惕那些故意表现可疑的玩家，他们可能是在引诱你们投票。"

```

通用提示词会被发送给所有玩家，帮助它们掌握情况，其中应包含：

1. 这个角色存在。
2. 这个角色的特别之处。

## 注册角色

在决定要设计一个角色之后，你应该进入/core/general.py，你需要修改其中的两个变量，以将这个角色注册进入代码。

```python
# 当前程序中，可以选择的角色以及对应的阵营
LEGAL_ROLE = {
    "villager": "good",
    "werewolf": "bad",
    "seer": "good",
    "witch": "good",
    "guard": "good",
    "hunter": "good",
    "joker": "neutral",
}

# 角色索引，在开局定义角色时，每个角色对应的编号
# 暂时只支持1位键值。如果数字不够，可以使用字母。
ROLE_INDEX = {
    "0": "villager",
    "1": "werewolf",
    "2": "seer",
    "3": "witch",
    "4": "guard",
    "5": "hunter",
    "6": "joker",
    "7": "fool",
    "8": "whitewolf",
}
```

你需要在`LEGAL_ROLE`中，将自己设计的角色的英文名加入其中，然后在`ROLE_INDEX`中，为其增加一个编号。只允许使用一位的键值，但允许使用英文字母。

完成了这一步骤之后，初始化阶段就会将你设计的新角色作为可选择项读入了。

虽然不是必须的，但我建议你在以下变量中同样注册自己的角色。

## 代码设计

本项目基于对对象编程的思想，因此你的代码应当写在对象中，进行修改。

为了保持代码格式规范，你应该：

### 在`/core/game.py`中的对象`Game`进行主要代码的编写

以以下例子作为参考（这是一个“守卫”角色的例子）。

```python
    def guard_guarding(self):
        """处理守卫的夜晚守护行动。

        该函数会与守卫玩家进行私聊，询问其当晚要守护的目标。
        获取目标后，将守护信息记录到守卫的上下文中，并更新当晚的守护列表。
        如果游戏中没有守卫角色，则直接返回。
        """

        def talk_guard(message: str):
            guard.private_chat(0, message)

        def record_guard(message: str):
            Context(self, 0, message, self.get_players(t="id", role="guard"))

        guard = self.get_players(role="guard")
        if not guard:
            return
        guard = guard[0]

        talk_guard(
            f"你今晚要保护谁？要保护的玩家编号请用[]包围，若不保护人则输出[0]。注意，你不可连续两晚保护同一个人{"" if self.last_guard == 0 else "，你昨晚保护了["+str(self.last_guard)+"]号玩家，因此你今晚无法保护这个玩家"}。例如'我要保护[7]号玩家'或'我不想保护人，[0]'。可以简短的给出理由。"
        )
        target = read_reply(guard)
        if target and target[0] != 0:
            record_guard(f"在{self.get_day()}的晚上，你保护了{target}号玩家。")
        self.guard_tonight.append(target[0])
```

比较推荐的步骤如下：

1. 设计两个函数，分别用于征求回答以及记录上下文。如在这个例子中，`talk_guard()`函数可以向`guard`发送一条消息（不写入上下文），`guard`在接到这个消息后会生成一条回复，而`record_guard()`则会将对应信息写进```guard```的上下文中。
2. 检查该角色是否存在且存活（`self.get_players()`默认只会返回存活角色），如果不存在则跳过。
3. 获取AI的回复。在这个例子中，使用了`talk_guard()`函数与`read_reply()`函数配合。`read_reply()`会获取到AI最新回复的某个消息。
4. 在此基础上，设计你的角色的具体步骤。

#### 单独阶段

如果你的角色单独管理一个阶段（如预言家在晚上睁眼），你需要在Game对象中的`routine()`方法中注册这个阶段的函数。下面是例子。

```python
    def routine(self):
        def check(role):
            return role in self.roles and self.roles[role] > 0

        init_routines = (((self.day_night_change, "寄生虫寄生"), check("parasite")),)

        routines = (
            ((self.day_night_change, "月亮升起"), True),
            ((self.guard_guarding, "守卫醒来"), check("guard")),
            ((self.werewolf_killing, "狼人醒来"), check("werewolf")),
            ((self.whitewolf_killing, "白狼醒来"), check("whitewolf")),
            ((self.seer_seeing, "预言家醒来"), check("seer")),
            ((self.witch_operation, "女巫醒来"), check("witch")),
            ((self.day_night_change, "太阳升起"), True),
            ((self.bear_roaring, "熊熊哈气"), check("bear")),
            ((self.public_discussion, "公共讨论"), True),
            ((self.vote_police_section, "警长投票"), True),
            ((self.vote_section, "陶片逐人"), True),
        )

        self.routines = []
        for routine in routines:
            if routine[1]:
                self.routines.append(routine[0])

        for routine in init_routines:
            if routine[1]:
                routine[0]()
```

函数后的字符串代表这个阶段的名字，会在游戏时显示。

对于会重复触发的阶段，你只需要在本地变量`routines`中修改；对于只需要一次初始化的阶段，你则需要在本地变量`init_routines`中修改。

#### 单独变量

如果你的角色需要一些在`Game`中使用的特殊变量，你可以在`init_special_role_prepartion`方法中进行初始化。

```python
    def init_special_role_prepartion(self):
        """初始化特殊变量

        此函数负责初始化某些特殊角色所需要的变量，如女巫需要记录当晚毒的人。
        """
        self.kill_tonight = []
        if self.roles["witch"] > 0:
            self.poisoned_tonight = []
        if self.roles["guard"] > 0:
            self.guard_tonight = []
            self.last_guard = 0
```

### 如果必须的话，在对象`Player`中写变量

对象`Player`位于`/core/player.py`中，管理着游戏进行中的每个玩家。

注意！为了代码的可读性，我十分不推荐你把游戏进行的代码写在`Player`中！只推荐你将必要的变量记录在`Player`中。

如果可以的话，尽量只写在`Player`的这个方法中：

```python
    def init_role_special(self):
        """根据角色初始化特殊属性。

        这是一个辅助函数，在玩家对象初始化时被调用。
        它会检查玩家的角色，并根据角色赋予其特殊的初始状态。
        例如，为'女巫'角色设置毒药和解药的初始拥有状态。
        """
        if self.role == "witch":
            self.poison = True
            self.antidote = True
        elif self.role == "hunter":
            self.revenge = True
        elif self.role == "joker":
            self.joker = True
```
